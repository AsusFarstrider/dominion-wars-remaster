# Credits, provenance and distribution

Unofficial fan restoration. Original game and Star Trek rights remain with their
respective owners; no endorsement is implied. Users supply legitimate supported
original files/media and the official patch. No no-CD or DRM bypass is included.

- **Dominion Wars Modernizer:** pinned 0.6.0-alpha foundation, source commit
  `4f889dea81385c3a604d09eb82452a1b48fafa25`, MIT license and bundled notices retained.
- **DDrawCompat 0.7.1 / Narzoul:** modified resolution-diag1/focus wrapper, BSD Zero
  Clause license, matching collected source and recorded build provenance. Normal
  launches clear telemetry flags. See the integration dependency inventory.
- **i6comp 0.20 / fOSSiL and Morlac:** pinned legacy cabinet helper. The preserved
  notice quotes its source headers: “Any use is authorized, granted the proper
  credit is given.” Attribution and exact helper hash accompany the foundation.
- **Jiri Dvorak's historical wrapper/source:** research provenance, not a newly
  incorporated runtime dependency in this package.
- **BOLTextract research:** relevant to separate archive-authoring work. Existing
  derivative tools remain subject to their documented GPL obligations; no blanket
  relicensing is applied. The default integration package does not import that
  private asset-authoring pipeline.

Newly project-authored integration/build/install/release code is MIT, with
[explicit scope/exceptions](LICENSING.md). Third-party licenses remain in force.
Publication clearance for an executable delta
is not inferred merely because it is a delta. Private Saber art, extracted game
assets, full game executables/archives, disc images, updater, reference models and
unfinished portrait/model work are excluded from the intended public package.

See [distribution inventory](../integration/docs/DISTRIBUTION.md). Historical
“pending approval” records in frozen source/package describe their creation-time
state; subsequent acceptance/publication evidence must be supplied separately,
without silently replacing the tested package.
