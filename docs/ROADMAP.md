# Restoration roadmap

First major milestone: a complete, faithfully restored first Federation mission,
including associated menus, interface, ships, environment and required assets.
No schedule or percentage-complete estimate is promised.

Work proceeds through specialized experiments, user-selected Master integration,
combined testing and user acceptance of an internal baseline. Release publishes
only separately approved snapshots of that baseline.

- Improve resolution, interface placement, input and stability without redesigning
  the recognizable original experience.
- Restore selected artwork, portraits, ship geometry and effects where it earns a
  visible benefit, preserving satisfactory original material.
- Extend tests to more Windows/GPU/monitor combinations and longer gameplay.
- Map remaining engine/asset conventions and address demonstrated bugs with
  narrowly targeted changes. Retain QUANTUM, missions, mechanics and balance.

Private specialist progress is not automatically integrated or publicly available.
Broader native-resolution support, further asset updates and quality-of-life changes must earn their
place through testing; this is not a promise to deliver every possible feature.
